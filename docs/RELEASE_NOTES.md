# Interval Timer Ver. 0.2 — リリース準備

## 主な変更

標準音源をYAMLカタログから選択できるようにしました。数式から生成したWAVを4種類追加し、通知ごとの無音・試聴・音量・再生回数・間隔を設定できます。

自分のMP3/WAVなどをページ内だけで一時利用できます。ファイル内容は送信・永続保存せず、再読み込みで解除します。Ver. 0.1のブラウザ保存設定・source指定を移行し、横16:9の投影表示と既存タイマー機能を維持しました。

チュートリアルとメタデータ・プライバシー・音源クレジットの説明を追加しました。説明文はOpenAI CodexによるAI草稿として記録し、プロジェクト管理者本人の執筆とは扱っていません。

- 自動テスト19件、Chrome/Edgeブラウザ検証36項目成功。詳しくは[テスト記録](TEST_REPORT.md)。

## 正式リリース前の確認事項

既存音源の扱いを確定してください。レゲエホーンとカウンターベルには規約上の再配布制限があり、音のたからばこ編集版ゴングも同梱許諾が未確認です。出典の表示だけで許諾済みとは扱いません。

従来のGitタグ・GitHub Releaseはありません。今回は変更を公開し、正式リリース用の説明を準備するところまでとし、タグやGitHub Releaseは作成していません。
