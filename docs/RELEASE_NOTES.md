# Interval Timer Ver. 0.2 — v0.2.0

## 主な変更

標準音源をYAMLカタログから選択できるようにしました。数式から生成したWAVを4種類追加し、通知ごとの無音・試聴・音量・再生回数・間隔を設定できます。

自分のMP3/WAVなどをページ内だけで一時利用できます。ファイル内容は送信・永続保存せず、再読み込みで解除します。Ver. 0.1のブラウザ保存設定・source指定を移行し、横16:9の投影表示と既存タイマー機能を維持しました。

チュートリアルとメタデータ・プライバシー・音源クレジットの説明を追加しました。説明文はOpenAI CodexによるAI草稿として記録し、プロジェクト管理者本人の執筆とは扱っていません。

## 検証・制約

- 自動テスト22件、Chrome/Edgeブラウザ検証42項目成功（うち旧URLキャッシュ対策2件）。詳しくは[テスト記録](TEST_REPORT.md)。
- macOS Safariは実画面操作で追加検証し、音源選択・デコード・試聴取消の問題を修正しました。詳しくは[Safariテスト記録](SAFARI_TEST_REPORT.md)。iPhone Safari、音響出力遅延、プロジェクター実機は未検証。
- 第三者MP3 3件を公開ファイルと全公開ブランチのGit履歴から削除しました。標準開始音はプログラム生成WAVへ変更し、保存済み設定の旧指定も移行します。
- テスト用MP3もプロジェクト生成WAVから作成し、第三者音源を使用しません。
- 投影・スピーカー実機およびiPhone Safariは機材がないため未検証です。

## 公開と履歴

正式リリースは `v0.2.0` です。音源除去に伴い過去のコミットIDが変わります。旧チェックアウトをmerge/pushすると削除音源が戻るため、必ず更新済み履歴を取得してください。第三者の取得済みコピーやGitHubの古いオブジェクト・キャッシュの消去は保証できません。

音源の過去の出典と調査結果はREADMEに保持しています。再配布許諾を取得したとの判断はしていません。
