FOCUS / MOVE / RECOVER

はじめての Interval Timer

運動する時間と休む時間を、見やすい大きな時計と通知音で切り替えます。まず短い時間で試し、投影前に音量を確かめましょう。

基本操作通知音自分の音源設定の保存投影困ったとき

1. 時間を決めて、動かしてみる

  1. タイマーを開き、「⚙ 設定」を押します。
  2. ACTは運動する時間です。経過時間を0から数えます。RESTは休憩時間で、残り時間を0まで数えます。
  3. 時間は秒で入力します。まずACT 10秒、REST 5秒、繰り返し2回にしてみましょう。通常の初期値はACT 600秒、REST 60秒、3回です。
  4. 進行方式を選び、「保存してタイマーへ」で反映します。
  5. STARTで開始予告（初期値3・2・1）、続いてACTが始まります。STOPで一時停止し、STARTで続きから再開します。RESETで最初に戻ります。

設定は開始後、一時停止中もロックされます。変更するときはRESETを押してください。音声ON/OFFはいつでも切り替えられます。

自動進行と手動進行

自動：ACT → REST → 次のACTと進みます。RESTの最後に予告音が鳴り、休憩時間の外に予告秒数は加算しません。

手動：ACT終了で待機し、STARTでRESTへ進みます。REST終了でも待機し、STARTで開始予告を経て次のACTへ進みます。

最後のACTでFINISHとなり、最後のRESTはありません。RESTを0秒にすると休憩を省略します。

2. 通知音を選び、試聴する

  1. 「⚙ 設定」→「表示・音声の詳細」を開きます。
  2. 開始予告、ACT開始、定期通知、終了前の警告、ACT終了のそれぞれで、音源のプルダウンを選びます。名前の下に説明が表示されます。
  3. 「試聴」で、その通知の音量・再生回数・間隔を確認します。試聴してもタイマーは動きません。別の音源を選ぶと試聴を停止します。
  4. 全体音量と通知ごとの音量は0〜1です。実際の音量はその積になります。再生回数は1〜10、間隔は0.05〜5秒で、前の音の終了を待たず指定間隔で重ねて鳴らします。
  5. 「保存してタイマーへ」で設定を反映します。

「無音」は選んだ通知だけを止めます。「音声 OFF」はすべての通知と試聴を止めます。全体音量0の場合も聞こえません。

初期設定ではACT中の定期通知が60秒ごと、警告が終了60秒前です。同時刻なら警告を優先します。ACTが60秒以下なら終了60秒前の警告は鳴りません。

標準のWAV音源4種類はプログラムで生成した音です。合成音も選べます。既存の第三者音源には再配布許諾が未確認のものがあります。出典・規約の確認状況はREADMEを参照してください。

3. 自分の音源を使う

  1. 通知のプルダウンから「自分の音源を使用…」を選びます。ファイル選択が開かない場合は「自分の音源を選ぶ」ボタンを押します。
  2. 端末のMP3またはWAVを選びます。OGG・M4A・AAC・FLACなどもブラウザが再生できれば使用できます。拡張子だけでなく、実際に音声を読み込めるか確認します。
  3. 選択後、ファイル名と「このページだけで有効」の案内が表示されます。プルダウンには再読み込み後に戻る標準音源を表示します。
  4. 「試聴」で確認し、「保存してタイマーへ」でタイマーへ戻ります。ローカル音源自体は保存されません。
  5. 「標準音源に戻す」、または標準音を選ぶと、ローカル音源を解除します。別のローカル音源を使う場合は、もう一度「自分の音源を使用…」を選びます。

上限は初期値20 MiB（20 × 1024 × 1024バイト）です。空・大きすぎる・読み込めないファイルは受け付けず、前の有効な音源を保持します。ファイル選択をキャンセルしても変更されません。

ファイルはブラウザの外へ送りません

利用者が選択した音源ファイルは、ブラウザ内でのみ使用されます。運営者のサーバーやGitHubにはアップロードされません。localStorageやIndexedDBにも保存しません。

再読み込み・ページを閉じる操作でローカル音源は失われ、再度選択が必要です。設定の保存・YAML書き出しにはファイル内容・ファイル名・Blob URLを含めず、標準音源の設定だけを書き出します。

4. 設定を保存・持ち運びする

「保存してタイマーへ」で時間・表示・標準音源の設定を同じブラウザに保存します。Ver. 0.1の保存設定は読み込み時に移行します。

「YAMLを編集・読み込み・書き出し」では、ファイルの読み込み、設定YAMLの編集と反映、ダウンロードができます。別の端末でも使うときはYAMLをダウンロードして持ち運びます。ローカル音源は別途選択してください。

「初期設定に戻す」で、ブラウザ保存設定とローカル音源を解除し、リポジトリの初期値を反映します。公開ページからリポジトリのYAMLを直接更新することはできません。

標準音源の情報はaudio.catalog、通知ごとの選択はselectedで管理します。説明文の作成者・作成日は音源の権利者・制作日とは別です。詳しい構造はREADMEにあります。

5. プロジェクターで使う

画面は横16・縦9です。「全画面」でタイマーを大きく表示します。設定は画面に重ねて開くため、通常はタイマーだけが表示されます。全画面を終了するには同じボタンやEscキーを使います。

投影中はページを前景に保ち、端末のスリープを防いでください。対応環境では画面のスリープ防止を要求しますが、OS・ブラウザによって利用できません。非表示・スリープ中の音声タイミングは保証できません。

よくある質問・音が鳴らないとき

音が鳴りません

STARTや試聴を押して音声を有効にしてください。音声ON、全体音量・通知音量、無音選択、端末の音量、出力先を確認します。ファイルを読み込めない場合は案内が表示され、標準音源では合成音に戻ります。ローカル音源はMP3/WAVなど別の形式でも試してください。

設定が反映されません

START後はRESETが必要です。画面の変更は「保存してタイマーへ」、YAML編集は「YAMLを反映」を押してください。保存済み設定があるブラウザでは、その設定を優先します。

URLで指定した音が鳴りません

従来どおり「URL・相対パスを指定…」でも指定できます。外部URLは配信元のCORS許可とHTTPSなどの条件を満たす必要があります。この方式では配信元へ取得通信が発生します。自分のファイルをブラウザ内だけで使いたいときはローカル音源を選んでください。利用条件も配信元で確認してください。

スマートフォンでも使えますか

現行ブラウザで利用できますが、音声形式・全画面・スリープ防止の対応は環境により異なります。投影は横向きの大きな画面を推奨します。操作説明ページは縦向きでも読めます。
