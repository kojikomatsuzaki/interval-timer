# interval-timer Ver. 0.1

16:9の横型ディスプレイに投影する、サーバー不要のインターバルタイマーです。

**公開アプリ:** https://kojikomatsuzaki.github.io/interval-timer/

## 使い方

1. 「⚙ 設定」を開き、ACT・RESTの秒数、繰り返し回数、進行方式を入力し「保存してタイマーへ」を押します。
2. STARTで電子音付きの3秒予告を開始。ACTは経過時間をカウントアップします。
3. STOPは現在の時間を保持して一時停止。STARTで続きから再開します。
4. RESETで最初に戻ります。実行中・一時停止中の時間設定はロックされます。音声ON/OFFはいつでも変更できます。
5. 初期表示はタイマーのみで、16:9の表示が画面内に収まります。「⚙ 設定」から設定を重ねて開き、「保存してタイマーへ」で閉じます。閉じるボタン・Escキーでもタイマーへ戻れます。「全画面」で投影画面を表示できます。全画面中も設定を開けます。

ACT・RESTの初期値は10分・1分、繰り返しは3回です。時間入力の単位は**秒**です。

## 自動と手動

- **自動:** 最初の予告 → ACT → REST → 次のACT。RESTの最後の3秒に予告音、REST終了時にホーンが鳴り、そのまま次のACTを開始します。RESTとは別の3秒は加算しません。
- **手動:** ACT終了で待機し、STARTでRESTへ。REST終了でも待機し、STARTで3秒予告を経て次のACTへ進みます。
- RESTが0秒の場合は休憩を省略し、次のACTの前に開始予告を入れます。
- 最終ACT終了でFINISHを表示します。最終ラウンドの後にRESTはありません。
- 開始予告中のSTOPも一時停止です。再開時に予告を最初からやり直しません。

## 音声

| タイミング | 初期音源・再生回数 |
| --- | --- |
| 開始予告 3・2・1 | 電子音各1回 |
| ACT開始 | レゲエホーン風の合成音1回 |
| ACT中の毎分 | 小音量のベル1回 |
| ACT終了1分前 | 小音量のベル2回、間隔0.18秒 |
| ACT終了（最終回を含む） | プロレスのゴング風の合成音5回、間隔0.2秒 |

10分のACTでは1〜8分にベル1回、9分に2回、10分にゴング5回。終了前ベルと定期ベルが同時なら終了前ベルを優先します。ACTが1分以下では「終了1分前」を鳴らしません。定期ベル間隔・終了前ベル時刻も変更可能です。

初期音源はWeb Audio APIで生成します。実際のレゲエホーン・プロレスの録音ではありません。画面の詳細設定で合成音やMP3/WAVのURLに変更し、全体音量・音源別の音量・連打回数・間隔を調整できます。独自音源は `audio/` に置き、例 `audio/horn.mp3` のように指定してください。外部音源にはCORSの許可が必要です。読み込み失敗時は警告を表示し合成音へ戻します。

ブラウザの制約により、音声はSTART・試聴・音声ONなどのユーザー操作で有効になります。音声OFF中は試聴もミュートされます。

## YAMLを正本にする設定管理

- リポジトリの [`config/timer.yaml`](config/timer.yaml) が初期設定です。
- 画面入力とYAML編集は同じ設定構造を使用します。画面変更はYAML欄に同期し、「保存してタイマーへ」で適用します。
- YAML欄の直接編集は「YAMLを反映」で適用します。
- 適用済み設定はlocalStorageへ保存し、同じブラウザで次回復元します。保存不可の場合は警告します。
- YAMLファイルの読み込み、ダウンロード、初期設定への復元に対応します。
- GitHub Pagesからリポジトリのファイルは直接更新できません。全端末共通の初期設定を変える際は、ダウンロードしたYAMLを `config/timer.yaml` にコミットしてください。
- ブラウザ保存済み設定がある端末はそれを優先します。リポジトリの新しい初期値に戻すには「初期設定に戻す」を押してください。
- 全UI設定はYAMLで管理できます。全画面・パネル開閉・START/STOP/RESETは一時的な画面操作として扱います。

`timer` の時間は秒、`audio` の音量は0〜1です。`countdown_seconds` は0〜30の整数、`rounds` は1〜999の整数。ACTは1〜86400秒、RESTは0〜86400秒。予告がRESTより長い場合、REST内で可能な整数秒分の予告だけ鳴ります。予告0秒では開始ホーンのみです。未対応のキー・範囲外の値・壊れたYAMLは拒否し、現在の設定を保持します。

## 時間精度

`performance.now()` を基準に、約50msごとに経過時間を再計算します。更新回数の加算を使わず、ACT・REST境界の遅れを次区間に引き継ぐため、遅延が累積しません。STOP時は経過を保持し、START時に時計の基準を更新します。

前景での計測・音声通知の目標許容誤差は±0.5秒。音声は画面から独立したWeb Audio時計に最大150ms先読みで予約し、連打も予約再生します。開始ホーンは区間切り替え時の更新で再生します。OS・ブラウザの負荷や音声出力機器の遅延により厳密な保証はできません。

非表示時や端末のスリープ中は、表示・通知のリアルタイム性を保証できません。復帰時は区間を進め、500ms以上過去の音を一斉再生しません。ブラウザ・OSによってスリープ中の単調増加時計の挙動は異なるため、投影中は画面を前景に保ってください。対応ブラウザではScreen Wake Lockを取得します。表示はACTの整数秒を切り捨て、RESTの残り整数秒を切り上げます。詳細設定で0.1秒表示にできます。

## ファイル構成

```text
index.html          画面構造
style.css           16:9・モバイル・全画面スタイル
app.js              設定・画面・操作・保存
engine.js           時計・状態遷移・音声マイルストーン
config.js           YAML読み書き・検証
audio.js            音声合成・音源読み込み・予約再生
config/timer.yaml   初期設定
audio/              独自音源配置先
vendor/             同梱js-yamlとMITライセンス
tests/              時間計測・進行・設定の自動検証
```

コードはHTML・CSS・JavaScriptを分離し、役割ごとの章立てを付けています。外部CDNへの実行時依存はありません。同梱のjs-yamlはMITライセンスです。

## ローカル実行とテスト

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
node --test tests/*.test.js
```

ES ModulesとYAMLの取得を使うため、ファイルの直接オープンではなくHTTPサーバーで開いてください。Chrome・Edgeなどの現行ブラウザを想定します。全画面・スリープ防止機能は環境により使用できない場合があります。

## GitHub Pages

`main` ブランチのルートをGitHub Pagesの公開元に設定します。`.nojekyll` を含む静的ファイルだけで動作します。ビルド不要です。
